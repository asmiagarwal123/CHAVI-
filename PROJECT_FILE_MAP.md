## Generated file classes

- `*.csv`: analysis tables, manifests, diagnostics, claims, issue registers, and validation crosschecks. Active authority depends on directory status, not extension.
- `*.json`: contracts, executable specifications, provenance, dataset metadata, and summaries.
- `*.yaml`: QC policies and approval records.
- `*.png` / `*.svg`: Step 4 task-level diagnostic/visualization outputs; no profile plots exist.
- `*.log`: execution logs for R2/Step 5B branches; historical evidence, not acceptance proof.
- `__pycache__/` and `.pytest_cache/`: generated interpreter/test caches; unused scientific artifacts. Several `.pytest_cache` paths are inaccessible in the current sandbox.
