# Recommended measurement specification — supervisor draft

| Decision | Recommendation | Evidence | Tradeoff | Limitation | Alternative |
|---|---|---|---|---|---|
| Research unit | Prespecify task-level scores first; treat domains/profile as conditional | Released columns and CNB accuracy/speed framework | Traceable | No validated common domain scale | Evidence-supported multi-task candidates |
| Five scores | LNB mcr; Face cr; Matrix cr; ER40 cr; dominant CTAP | Exact released fields and dossier | Fixed identity | Proxy is not a validated composite | Task-level route |
| QC | Documented valid/likely-valid with all applicable QC; strict V-only and unresolved-inclusive sensitivities | Exact dictionary meanings | Transparent exclusions | QC scope unresolved | Task-specific approval |
| Completeness | Require all selected components | Explicit set intersection | No silent substitution | Lower coverage | Reduced four-domain sensitivity |
| Pairing | First two eligible primary candidate; scheduled ses-1/ses-2 sensitivity | Pair manifest | Eligibility-aligned | Pair rule remains provisional | All unordered pairs |
| Direction/weighting | Freeze only supported accuracy/speed directions; no weighting yet | Methods distinguish accuracy/speed | Avoids invented scale | Profile level not final | Prespecified weighting after review |
| Age/interval | Descriptive age and nominal intervals; no fitted age model | Rounded/anonymized timing | Separates development from error | Adjustment unresolved | Leakage-safe model after approval |

This package supports review, not final scoring or reliability estimation.
