# Step 2C correction record

Step 2C corrected five implementation defects: QC classes now use exact dictionary meanings; undocumented F, no-autovalidation text, and unknown V/VC remain unresolved; documented likely-valid is distinct from valid; and unresolved-inclusive eligibility retains the observed-score base except explicit invalid/skipped components. Profile-level unresolved, all-unresolved, and mixed-unresolved/invalid counts are reported separately.

Pair accounting now emits participant-level pair manifests with all unordered pairs, first-two pairs, and complete scheduled pairs. Even-sample medians are conventional arithmetic medians; missing, unparseable, and nonpositive timing are explicit. Fixed-profile comparability is uncertain unless documented, and the sub-20812 ses-2 continuation cannot create a CNB occasion.

Loss accounting uses overlapping reason flags plus a documented sequential flow. ‘No documented cognitive phenotype’, missing selected score, QC exclusion, comparability exclusion, and unresolved classification are not silently conflated.

The corrected audit is feasibility and design work only. No composite, standardization, age adjustment, reliability, prediction, or Evidence Engine was run.
